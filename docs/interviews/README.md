# Interview write-ups

One file per conversation: `<YYYY-MM-DD>-<initials>.md` (initials of the
person interviewed, not you). Do Rep 4 first — this is the only Milestone 2
deliverable that depends on someone else's calendar.

Each write-up needs: date, length, who they are, the five past-tense
questions you asked, the workaround they already use, and three verbatim
quotes.

No real user available? Substitute a competitive scan of three existing
tools instead, and say plainly why there's no external user — don't invent
one. A fabricated interview is an honor-code issue, not a two-point
deduction; see `docs/ai-usage.md` for the AI-disclosure boundary on this
milestone.

This file is a placeholder so the empty folder survives `git add` — delete
it once the first real interview file lands here.
